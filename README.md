WAR OF PAPER (WoP)
==================
[English]
War of Paper is an open-source, free, and ad-free 3D game prototype built in Godot 3.5.3.
This repository starts with a primitive base (character animations and camera/rotation controls)
so contributors can test, improve, and help expand the project together.

How to run:
- Open the project using Godot 3.5.3.
- Run the main/character scene to test current animations and controls.

Looking for help with:
- unique Gameplay mechanics, camera & movement, UI, performance, and bug fixes.
